REAL-WORLD TESTING PHASE – GYMPRO FULL SYSTEM TEST

Do not add new features unless a bug fix is required.

Use Replit testing tools to run a full real-world test of the GymPro application.

Goal:
Verify that all major modules work together correctly and produce accurate accounting, inventory, payroll, membership, and audit results.

Create test data, run workflows, validate results, and return a checklist with PASS / FAIL / WARNING.

Test these areas:

1. Authentication & Permissions
- Admin login
- Manager login
- Staff login
- Page access restrictions
- View Cost restriction
- View Profit restriction
- View Accounting restriction
- Manage Members restriction
- Manage Payroll restriction
- Manage Inventory restriction

2. Settings
- Gym name saves correctly
- Logo settings save correctly
- USD/CDF exchange rate saves correctly
- Language switching works for EN / FR / AR
- Arabic RTL layout works
- Receipt footer/settings appear on print templates
