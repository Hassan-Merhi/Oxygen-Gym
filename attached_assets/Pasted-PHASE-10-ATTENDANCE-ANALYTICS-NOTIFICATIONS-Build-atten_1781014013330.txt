PHASE 10 – ATTENDANCE ANALYTICS + NOTIFICATIONS

Build attendance reporting and notifications using existing members, check-ins, plans, inventory, payroll, and dashboard data.

Important:
- Do not modify existing accounting logic.
- Use existing check_ins table.
- Use existing permissions.
- Use existing activity logs.

1. Attendance Dashboard

Create /attendance page.

Summary cards:
- Check-ins Today
- Check-ins This Week
- Check-ins This Month
- Active Members Today
- Average Daily Attendance

2. Attendance Reports

Charts:
- Daily attendance (last 30 days)
- Monthly attendance (last 12 months)
- Hourly attendance trend
- Top attending members

Tables:
- Today's attendance
- This week's attendance
- Member attendance history

Filters:
- Date range
- Member
- Plan

3. Member Attendance Stats

Add attendance tab inside member profile.

Show:
- Total check-ins
- Last check-in
- Check-ins this month
- Average visits per month
- Attendance calendar/history

4. Notifications Center

Create notification bell in top navigation.

Notification types:

Membership:
- Expiring in 30 days
- Expiring in 14 days
- Expiring in 7 days
- Expiring today

Inventory:
- Low stock products
- Out of stock products

Payroll:
- Payroll due soon

Members:
- Frozen memberships
- Inactive members

5. Notification Page

Create /notifications

Columns:
- Type
- Priority
- Message
- Date
- Status (Read/Unread)

Filters:
- Type
- Read/Unread

6. Dashboard Widgets

Add:
- Expiring memberships widget
- Low stock widget
- Notifications widget

7. Activity Logs

Log:
- Notification read
- Notification dismissed

8. Permissions

Without dashboard access:
- No dashboard widgets

Without inventory permissions:
- Hide stock notifications

Without payroll permissions:
- Hide payroll notifications

9. UI Requirements

- Bell icon with unread count
- Dropdown preview
- Mark read
- Mark all read
- Mobile responsive
- EN / FR / AR translations
