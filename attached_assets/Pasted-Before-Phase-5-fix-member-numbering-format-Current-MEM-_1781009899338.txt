PHASE 5 – PAYMENTS, VOUCHERS, AND CASH LEDGER

Build the full cash-only payments system.

Important:
- Cash only for now.
- Support USD and CDF.
- Every transaction must store the exchange rate used at the time.
- Do not recalculate old transactions if the exchange rate changes later.
- Accounting must be accurate.
- All payments/vouchers must update the cash ledger.
- Use existing permissions, activity logs, and numbering service.

1. Payments Page

Create /payments page with:
- Search
- Date range filter
- Type filter: Received, Paid
- Category filter
- Currency filter: USD, CDF
- Pagination
- Export/print view placeholder

Columns:
- Payment number
- Date
- Type
- Category
- Amount
- Currency
- Exchange rate used
- USD equivalent
- CDF equivalent
- Account
- Linked member/customer/vendor/staff
- Notes
- Created by

2. Record Payment

Create payment modal.

Fields:
- Type: Received or Paid
- Category:
  - Membership
  - Product Sale
  - Expense
  - Payroll
  - Stock Purchase
  - Other
- Amount
- Currency
- Exchange rate used
- Account: Cash
- Linked member/customer/vendor/staff optional
- Notes

Rules:
- Received increases cash.
- Paid decreases cash.
- Store amount in original currency.
- Store exchange rate used.
- Store normalized USD amount.
- Store normalized CDF amount.

3. Cash Ledger

Create cash ledger engine.

Every transaction creates a ledger entry:
- Date
- Source type: Payment, Voucher, Sale, Payroll, Stock Purchase
- Source number
- Direction: In or Out
- Amount
- Currency
- Exchange rate used
- USD value
- CDF value
- Running balance USD
- Running balance CDF
- Description
- Created by

4. Vouchers Page

Create /vouchers page.

Voucher types:
- Cash Receipt Voucher
- Cash Payment Voucher
- Expense Voucher
- Customer Payment Voucher

Fields:
- Voucher number: VCH-000001
- Date
- Voucher type
- Paid to / Received from
- Amount
- Currency
- Exchange rate used
- Account: Cash
- Category
- Description
- Created by

Rules:
- Cash receipt voucher increases cash.
- Cash payment voucher decreases cash.
- Expense voucher decreases cash and counts as expense.
- Customer payment voucher increases cash.

7. Permissions

- Cannot access Payments, Vouchers, Accounts, or ledger details

Users without Manage Accounting:
- Cannot create/edit vouchers or payments

Users without View Profit:
- Cannot see profit-related fields
