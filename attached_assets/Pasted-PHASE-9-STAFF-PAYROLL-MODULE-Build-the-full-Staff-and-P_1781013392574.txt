PHASE 9 – STAFF & PAYROLL MODULE

Build the full Staff and Payroll system using existing users, permissions, cash ledger, payments, and activity logs.

Important:
- Staff users already exist for login/permissions.
- This phase should add staff employee records and payroll.
- Payroll is cash only.
- Support USD and CDF.
- Store exchange rate used at payment time.
- Paid payroll must decrease cash and create ledger entry.
- Users without Manage Payroll cannot run payroll.
- Users without View Accounting cannot see payroll payment/ledger details.

1. Staff Employee Records

Create staff employee profile fields:
- Staff number: STF-000001
- Linked login user optional
- Full name
- Phone
- Email
- Role/title
- Hire date
- Salary amount
- Salary currency: USD/CDF
- Payment frequency: Monthly / Weekly / Daily
- Status: Active / Inactive / Archived
- Notes

2. Staff Page

Update /staff page so it has two tabs:
- Login Users & Permissions
- Employee Records

Employee Records tab should include:
- Search
- Status filter
- Role filter
- Add/edit/archive staff employee
- View staff profile

3. Payroll Page

Create /payroll page.

Payroll list columns:
- Payroll number: PRL-000001
- Staff name
- Pay period start
- Pay period end
- Salary amount
- Bonus
- Deduction
- Net pay
- Currency
- Exchange rate used
- Status: Draft / Paid / Cancelled
- Paid date
- Created by
- Actions

4. Generate Payroll

Create payroll modal:
- Select staff employee
- Pay period start/end
- Base salary auto-filled
- Bonus
- Deduction
- Currency
- Exchange rate used
- Notes

Formula:
Net Pay = Base Salary + Bonus - Deduction

Create payroll as Draft first.

5. Mark Payroll as Paid

When marked paid:
- Status becomes Paid
- Paid date is saved
- Create payment record category Payroll
- Create cash ledger OUT entry
- Update accounts/payroll expense automatically
- Add activity log

6. Cancel Payroll

Cancel payroll:
- Only allowed if not paid, unless Admin overrides
- If paid payroll is cancelled, create reversing ledger entry instead of deleting
- Add activity log

7. Payroll Slip Print

Printable payroll slip should show:
- Gym logo
- Gym name
- Staff name
- Staff number
- Pay period
- Base salary
- Bonus
- Deduction
- Net pay
- Currency
- Paid date
- Prepared by
- Signature line

8. Staff Profile

Staff profile should show:
- Basic info
- Payroll history
- Total paid this year
- Last payroll date
- Notes

9. Permissions

Without Staff page access:
- Cannot open Staff page

Without Manage Staff:
- Cannot add/edit/archive employee records

Without Payroll page access:
- Cannot open Payroll page

Without Manage Payroll:
- Cannot generate/pay/cancel payroll

Without View Accounting:
- Hide ledger/payment technical details

10. Activity Logs

Log:
- Staff employee created
- Staff employee edited
- Staff employee archived
- Payroll generated
- Payroll marked paid
- Payroll cancelled
- Payroll slip printed

11. UI Requirements

- Clean tabs on Staff page
- Payroll table with filters
- Add/edit modals
- Print slip button
- Loading states
- Empty states
- Toast notifications
- Full EN / FR / AR translations

Stop after Phase 9 and wait for approval.
